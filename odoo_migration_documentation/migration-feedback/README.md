# Migration feedback

Área opcional para guardar feedback bruto, notas, logs e tracebacks das execuções manuais.

O colega pode simplesmente colar os erros diretamente no Codex/Claude. Esta pasta serve apenas quando for útil guardar evidência no repositório.

Sugestão de organização:

```text
migration-feedback/runs/RUN-YYYY-MM-DD-XX/
├── notes.md
├── modules-tested.md
├── logs/
└── screenshots/
```

Nunca guardar passwords, tokens, dumps, dados pessoais sensíveis ou filestore nesta pasta.
