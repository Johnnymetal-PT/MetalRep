# MIG-0001 - Módulos presos em "Cancelar Instalação"

## Contexto

Durante o piloto de migração Odoo 17.0 -> 18.0, já numa BD em Odoo 18.0, o tester tentou instalar módulos custom pela interface Apps. Os módulos apareciam presos em estado pendente.

## Evidência

O tester reportou inicialmente:

```text
Tentei desinstalar os 2 módulos que dizem "Cancelar Instalação" e voltar a instalar mas ficam presos neste estado e não avança. Já na BD em 18.0.
```

Também reportou:

```text
Desinstala o módulo, mas nunca o instala.
```

O SQL posterior mostrou:

```text
pg_tecidos: state=uninstalled, latest_version=NULL
pg_sale_salesperson: state=uninstalled, latest_version=NULL
```

Atualização posterior do tester:

```text
o que estava em falta era o caminho dos addons no odoo.conf
```

## Classificação

- Fase: Instalação módulo
- Camada técnica: Manifest/Dependências
- Severidade: S3 - Média
- Estado: Corrigido
- Causa raiz: RC-0001
- Estado da causa raiz: confirmed

## Módulos afetados

- `pg_sale_salesperson`
- `pg_tecidos`

## Ficheiros relacionados

- `custom_addons/pg_sale_salesperson/__manifest__.py`
- `custom_addons/pg_tecidos/__manifest__.py`

## Causa raiz

O caminho dos addons custom não estava incluído no `addons_path` do `odoo.conf`, pelo que o Odoo não carregava corretamente os módulos copiados.

## Correção aplicada

Configuração externa corrigida no servidor, adicionando o caminho dos addons custom ao `addons_path` do Odoo 18. Não houve alteração de código no repositório para este erro.

## Reteste

Após corrigir o `addons_path`, o servidor passou a encontrar os addons e revelou o próximo erro real: `MIG-0003`.

## Validação funcional

Pendente. A validação funcional só deve ser feita depois de os módulos instalarem/atualizarem com sucesso.
