# MIG-0005 - XPath `move_ids_without_package/tree` não encontrado

## Contexto

Durante a instalação do módulo `pg_packing_list_custom` em Odoo 18, o carregamento XML falhou ao aplicar uma view herdada de `stock.picking`.

## Evidência

Erro principal:

```text
odoo.tools.convert.ParseError: while parsing /ProgGest/Odoo18/Pglobal/addons/pg_packing_list_custom/views/stock_picking_views.xml:6
O elemento '<xpath expr="//field[@name='move_ids_without_package']/tree">' não foi encontrado na vista ascendente
```

Contexto da view:

```text
name: stock.picking.form.packing.columns
view.model: stock.picking
xmlid: stock_picking_form_packing_columns
```

## Classificação

- Fase: Instalação módulo
- Camada técnica: XML/View/XPath
- Severidade: S1 - Bloqueante
- Estado: Retestado OK
- Causa raiz: RC-0005
- Estado da causa raiz: probable

## Módulo afetado

- `pg_packing_list_custom`

## Ficheiro afetado

- `custom_addons/pg_packing_list_custom/views/stock_picking_views.xml`

## Causa provável

A view base `stock.view_picking_form` em Odoo 18 já não expõe a subview de `move_ids_without_package` como `tree` nesse ponto. O XPath herdado do módulo procurava:

```xml
//field[@name='move_ids_without_package']/tree
```

Em Odoo 18, a subview deve ser endereçada como `list`.

## Correção aplicada

Alterado o XPath:

```xml
//field[@name='move_ids_without_package']/tree
```

para:

```xml
//field[@name='move_ids_without_package']/list
```

## Ficheiros alterados

- `custom_addons/pg_packing_list_custom/views/stock_picking_views.xml`

## Reteste recomendado

Copiar a alteração para o servidor Odoo 18 e repetir a instalação:

```bash
/ProgGest/Odoo18/python-venv/bin/python3.10 /ProgGest/Odoo18/Server/odoo-bin \
  -c /ProgGest/Odoo18/odoo.conf \
  -d PRIVATE_test_18.0_2026_06_01_11_38 \
  -i pg_packing_list_custom \
  --stop-after-init
```

Reteste OK: o tester reportou que todos os módulos instalaram com sucesso.
