# MIG-0006 - Logs INFO repetidos em `stock.move.write`

## Contexto

Durante a tentativa de instalar `pg_packing_list_custom`, o tester observou uma mensagem constante no log, mudando apenas o ID do movimento.

## Evidência

```text
2026-06-01 17:19:29,735 55276 INFO PRIVATE_test_18.0_2026_06_01_11_38 odoo.addons.pg_tecidos.models.stock_move: [STOCK MOVE WRITE] No partner change detected for stock moves [10666].
```

## Classificação

- Fase: Instalação módulo
- Camada técnica: Python/ORM
- Severidade: S5 - Observação
- Estado: Corrigido
- Causa raiz: RC-0006
- Estado da causa raiz: confirmed

## Módulo afetado

- `pg_tecidos`

## Ficheiro afetado

- `custom_addons/pg_tecidos/models/stock_move.py`

## Causa raiz

O override de `stock.move.write()` em `pg_tecidos` registava uma condição normal em nível `INFO` sempre que o `write()` não alterava `partner_id`. Como `stock.move` recebe muitos writes durante operações de stock e instalação, a mensagem poluía o log sem indicar falha.

## Correção aplicada

Baixado o log de `INFO` para `DEBUG`:

```python
_logger.debug(f"[STOCK MOVE WRITE] No partner change detected for stock moves {self.ids}.")
```

## Ficheiros alterados

- `custom_addons/pg_tecidos/models/stock_move.py`

## Reteste recomendado

Copiar a alteração para o servidor e reiniciar o serviço Odoo 18:

```bash
sudo systemctl restart odoo18
```

Depois repetir a instalação de `pg_packing_list_custom`. Se houver falha real, colar o traceback completo; esta mensagem isolada não é erro bloqueante.
