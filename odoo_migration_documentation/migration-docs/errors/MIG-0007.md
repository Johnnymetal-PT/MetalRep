# MIG-0007 - XPath `order_line/tree` não encontrado em compras

## Contexto

Durante a instalação do módulo `pg_multi_discount` em Odoo 18, o carregamento XML falhou ao aplicar uma view herdada de `purchase.order`.

## Evidência

Erro principal:

```text
odoo.tools.convert.ParseError: while parsing /ProgGest/Odoo18/Pglobal/addons/pg_multi_discount/views/purchase_order_views.xml:3
O elemento '<xpath expr="//field[@name='order_line']/tree">' não foi encontrado na vista ascendente
```

Contexto da view:

```text
name: sh.purchase.order.form.view
view.model: purchase.order
xmlid: sh_purchase_order_form_view
```

## Classificação

- Fase: Instalação módulo
- Camada técnica: XML/View/XPath
- Severidade: S1 - Bloqueante
- Estado: Retestado OK
- Causa raiz: RC-0005
- Estado da causa raiz: probable

## Módulo afetado

- `pg_multi_discount`

## Ficheiro afetado

- `custom_addons/pg_multi_discount/views/purchase_order_views.xml`

## Causa provável

Em Odoo 18, as subviews one2many passaram a ser endereçadas como `list` em vez de `tree`. O módulo herdado de Odoo 17 procurava:

```xml
//field[@name='order_line']/tree
```

O mesmo padrão existia também nas views de faturas e vendas do módulo.

## Correção aplicada

Alterados os XPaths de `tree` para `list`:

- `purchase_order_views.xml`: `order_line/tree` -> `order_line/list`
- `account_move_views.xml`: `invoice_line_ids/tree` -> `invoice_line_ids/list`
- `sale_order_views.xml`: `order_line/tree` -> `order_line/list`

`sale_order_views.xml` está comentado no manifest neste momento, mas foi atualizado preventivamente por ter a mesma causa.

## Ficheiros alterados

- `custom_addons/pg_multi_discount/views/purchase_order_views.xml`
- `custom_addons/pg_multi_discount/views/account_move_views.xml`
- `custom_addons/pg_multi_discount/views/sale_order_views.xml`

## Reteste recomendado

Copiar as alterações para o servidor Odoo 18 e repetir a instalação:

```bash
/ProgGest/Odoo18/python-venv/bin/python3.10 /ProgGest/Odoo18/Server/odoo-bin \
  -c /ProgGest/Odoo18/odoo.conf \
  -d PRIVATE_test_18.0_2026_06_01_11_38 \
  -i pg_multi_discount \
  --stop-after-init
```

Reteste OK: o tester reportou que todos os módulos instalaram com sucesso.

## Validação funcional

Pendente. Validar descontos múltiplos em compras e faturas. Se `sale_order_views.xml` for reativado no manifest, validar também vendas.
