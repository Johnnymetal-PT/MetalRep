# MIG-0004 - Warning `BD_Geral` não instalável

## Contexto

Durante o carregamento do registry, o log também apresentou um aviso relacionado com o módulo `BD_Geral`.

## Evidência

```text
WARNING ? odoo.modules.graph: module BD_Geral: not installable, skipped
```

## Classificação

- Fase: Carregamento registry
- Camada técnica provável: Manifest/Dependências
- Severidade: S5 - Observação
- Estado: Em triagem
- Causa raiz: RC-0004
- Estado da causa raiz: probable

## Módulo afetado

- `BD_Geral`

## Causa provável

O módulo `BD_Geral` é referenciado pela base/lista de módulos, mas no repositório piloto não há evidência de um addon instalável com esse nome técnico. Existe `pg_bd_geral_security`, que contém comentários indicando que a app custom "BD Geral" não está no repo e que o nome técnico precisa de confirmação.

## Correção proposta

Não corrigir ainda. Primeiro desbloquear o registry com `MIG-0003`. Depois confirmar se:

- existe um addon técnico `BD_Geral` que ainda precisa ser copiado;
- o nome técnico correto é outro;
- ou o módulo deve ser removido/desmarcado na BD migrada.

## Reteste recomendado

Depois de resolver `MIG-0003`, verificar se o warning persiste no arranque/update.
