# MIG-0003 - Dependência Python `astor` em falta

## Contexto

Após corrigir o `addons_path` do Odoo 18, o servidor passou a encontrar os addons custom. O carregamento do registry falhou ao importar o módulo `base_view_inheritance_extension`.

## Evidência

Excerto relevante do log:

```text
CRITICAL ? odoo.modules.module: Couldn't load module base_view_inheritance_extension
ERROR ? odoo.modules.registry: Failed to load registry
```

Traceback final:

```text
File "/ProgGest/Odoo18/Pglobal/addons/base_view_inheritance_extension/models/ir_ui_view.py", line 10, in <module>
    import astor
ModuleNotFoundError: No module named 'astor'
```

O manifest do módulo declara a dependência:

```python
"external_dependencies": {"python": ["astor"]},
```

## Classificação

- Fase: Carregamento registry
- Camada técnica: Manifest/Dependências
- Severidade: S1 - Bloqueante
- Estado: Retestado OK
- Causa raiz: RC-0003
- Estado da causa raiz: confirmed

## Módulo afetado

- `base_view_inheritance_extension`

## Ficheiros relacionados

- `custom_addons/base_view_inheritance_extension/__manifest__.py`
- `custom_addons/base_view_inheritance_extension/models/ir_ui_view.py`

## Causa raiz

A dependência Python `astor` está declarada no manifest e é importada por `models/ir_ui_view.py`, mas não está instalada no venv usado pelo serviço Odoo 18.

## Correção aplicada

O tester atualizou primeiro `pip` no venv Odoo 18 e depois instalou/confirmou `astor`:

```bash
/ProgGest/Odoo18/python-venv/bin/python3.10 -m pip install --upgrade pip
/ProgGest/Odoo18/python-venv/bin/python3.10 -m pip install astor
```

Resultado reportado:

```text
Successfully installed pip-26.1.2
Requirement already satisfied: astor ... (0.8.1)
```

## Reteste

Reteste OK. O tester reportou que não houve erros ao instalar os módulos.

## Validação funcional

Pendente. Como a instalação passou, falta validar o comportamento funcional dos módulos instalados contra Odoo 17.

## Próxima ação

Avançar para os restantes módulos. Se a instalação continuar a passar, validar comportamento funcional e documentar diferenças.
