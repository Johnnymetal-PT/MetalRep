# Custom addons

Colocar aqui os addons customizados originalmente desenvolvidos para Odoo 17 que serão testados/adaptados em Odoo 18.

Recomendações:

- manter cada addon na sua pasta técnica;
- não commitar ficheiros temporários, caches, dumps ou filestore;
- usar branches/commits pequenos quando houver alterações;
- por defeito, Codex/Claude devem ler estes ficheiros apenas para análise e documentação.

Exemplo:

```text
custom_addons/
├── custom_sale_margin/
├── custom_account_reports/
└── custom_stock_rules/
```
