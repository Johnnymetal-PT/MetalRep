## O que se vai ver e porquê

Cada trabalho de design de interiores é um projeto. A aplicação **Projeto** mostra em que fase está cada trabalho, quem é responsável, os prazos e as horas gastas — e liga tudo ao orçamento aceite pelo cliente.

A equipa já começou: o José Correia criou o projeto **«Adélia Reis - Acessório Doseador»** e a Cristina o projeto **«Manuela Melo_estante suspensa»**. Esta sessão parte desses exemplos.

## O circuito, passo a passo

**1. Como nasce um projeto**

- **Automaticamente** (recomendado): ao confirmar um orçamento com um serviço configurado para criar projeto (sessões 2 e 3). Fica ligado ao cliente e ao pedido de venda.
- **Manualmente**: **Projeto** → **Novo** → nome e cliente. Indicar sempre o cliente.

**2. As fases**

- As tarefas avançam por colunas (fases). Arrastar o cartão para a coluna seguinte.
- Todos os projetos usam as mesmas fases, definidas pela Cristina no modelo de projeto **«Geral»**: **Ficha cliente → Orçamentação → Orçamentos fechados → Aditamentos → Financeiro → Encomendas → Entregas → Auditoria**.
- Para criar um projeto já com estas fases: **Projeto › Configuração › Modelos de projeto** → **«Geral»**.

**3. Trabalhar com tarefas**

- Dentro do projeto: **+** no topo de uma coluna, ou **Novo**.
- **Título**, **Responsáveis**, **Prazo final**, **Marcadores**, **Prioridade** (estrela).
- Separador **Descrição** — o que foi pedido: medidas, materiais, notas da reunião.
- **Subtarefas** — dividir um trabalho grande (ex.: Montagem › Cozinha, Quarto).
- Anexos (clipe no histórico) — plantas, renders 3D, fotografias da obra.

**4. Registar horas**

- Separador **Planilhas de horas** da tarefa: data, descrição, horas.
- Permite saber quanto tempo levou cada projeto — e comparar com o que foi orçamentado.

**5. Acompanhar todos os projetos**

- **Tarefas › Minhas tarefas** — só o que está atribuído a mim.
- **Relatórios › Análise de tarefas** — ponto de situação de todos os projetos.

- Histórico completo de cada projeto (mensagens, anexos, alterações).
- Horas reais por projeto, para orçamentar melhor os próximos.
