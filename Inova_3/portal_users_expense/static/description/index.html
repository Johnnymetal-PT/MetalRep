Portal User Expense (Manage expenses easily from the website portal)

This module allows portal users to manage their expense reimbursements directly from the website portal. Employees can easily create, submit, and monitor expense requests without needing back-end access, streamlining the reimbursement process and improving transparency.

Key Features

Create Expense Requests
Submit expenses for approval and track the reimbursement status.
Employees don't need Odoo backend access, everything is available in the portal.
Works seamlessly with the standard Odoo Expense module.

Link Employee with Portal User, The employee is connected with a related user to allow portal access.

Access “My Expenses” from Portal, Employees can see their expense menu directly inside the portal.

Create New Expense Request, Fill in expense details, attach bills, and submit for approval.

Successful Submission Acknowledgement, A confirmation message appears after expense submission.

Track and Manage Expenses, Employees can view, search, and manage all their submitted expenses from the portal.

Manager Approval in Backend, Submitted expenses are visible to managers/admins for validation and approval.
